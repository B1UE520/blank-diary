# 《空白页日记》｜沉浸式ARG网页解谜游戏
> 原生家庭创伤主题交互ARG，网页端即可游玩，包含日记、NPC对话、吉他乐谱谜题、PPT隐藏线索多条叙事线。

## ⚠️ 内容预警
本作品包含：原生家庭压力、自我否定、情绪崩溃、进食焦虑相关描写。
**如果有相似创伤经历，请酌情游玩，感到不适请立刻退出。**
作品为虚构艺术创作，所有剧情仅为故事表达，不代表现实建议。

## 🎮 游戏简介
玩家偶然发现一本缺页的日记本，顺着碎片化线索，拼凑出一位女孩的成长故事。
随着探索推进，SAN值缓慢侵蚀，你会看见她长期承受家庭重压，在压抑里挣扎；
通过解锁多层线索：网页论坛留言、手机聊天记录、隐藏日记、吉他《晴天》乐谱密码、PPT黑白隐藏图层谜题，逐步揭开全部真相。

结局：女孩没有说服母亲，也没有改变过去的创伤，但在朋友陪伴下，学会与自己和解。

## 🧩 解谜清单（无剧透，仅提示）
1. 网页日记碎片、NPC聊天记录阅读收集线索
2. 吉他谜题：《晴天》吉他谱提取音符数字密码
3. PPT解谜：下载配套PPT，切换黑白模式查看隐藏背景线索
4. 隐藏彩蛋：母亲的私人日记（额外支线，完善人物悲剧底色）

## 📌 游玩方式
1. 打开网页首页 `index.html`
2. 跟随页面提示探索，收集线索，输入密码解锁新页面
3. 【重要】遇到PPT解谜关卡：点击页面下载「林默的自我介绍.pptx」，本地用PowerPoint打开，切换黑白模式寻找隐藏信息。

> ⚠️ PPT文件需要下载到本地电脑打开，网页预览无法实现黑白图层切换解谜。
